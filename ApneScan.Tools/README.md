# ApneScan.Tools

Tools for ApneScan building, testing, packaging, verification, etc.

## Quickstart

### Powershell

```
function n2 { dotnet run --project ApneScan.Tools -- $args }
```

### Bash

```
alias n2="dotnet run --project ApneScan.Tools --"
```

For more documentation see the [wiki](https://github.com/cyanfish/apnescan/wiki/2.-ApneScan.Tools).
